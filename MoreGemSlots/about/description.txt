Essence slots stop being a flat three and start being something you earn. This alters gameplay, so please do not bring it into games with people who did not ask for it.

[h2]How slots are earned[/h2]
[list]
[*]Every memory starts with [b]3[/b] slots, as it always did
[*]Hero level [b]10*[/b] — every memory gains a slot
[*]Hero level [b]20*[/b] — every memory gains another
[*]A memory upgraded to [b]+5*[/b] gains a slot of its own
[*]A memory upgraded to [b]+10*[/b] gains another
[/list]
[i]* These four numbers can be changed in the mod's settings.[/i]

A fully levelled hero holding a fully levelled memory ends up with [b]7[/b] slots on it, which is the most the interface can show.

Slots can be lost as well as gained. Swap a levelled memory for a fresh one and its extra slots go with it — the essences in them move to the nearest free slot on that memory, and if there is nowhere left they drop at your feet rather than vanishing into a slot nobody can reach.
